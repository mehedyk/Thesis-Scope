# Limitations & ethics

- AI detectors give probabilities, not proof. False positives are common on formulaic, technical or non-native English writing.
- Do not use this tool to accuse or penalise anyone. Use it as a self-check before submission and keep drafting history (Word/Google Docs version history) as the best defence against a wrong flag.
- Open Pangram EditLens models: CC BY-NC-SA 4.0 (non-commercial); the authors state they should not be used to enforce AI policies. Qwen2.5 models: check each model's license. Community model copy used: `CoderBak/editlens_roberta_modelkit`.
- Online checks send short text phrases to third-party services (infini-gram, DuckDuckGo, Semantic Scholar, Crossref). Disable them for confidential work.
- Plagiarism coverage is partial: sampled sentences, open sources only, no private databases.
